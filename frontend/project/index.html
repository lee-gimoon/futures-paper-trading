WHAT YOU CAN PRACTICE

무엇을 연습할 수 있나요?

기능 이름만 나열하지 않고, 각 기능이 어떤 선물거래 개념을 학습하게 하는지 설명합니다.

01

실시간 호가와 캔들

BTCUSDT 상위 20호가와 여러 시간 단위의 캔들을 한 화면에서 확인합니다.

02

호가 레벨 기반 체결

시장가·지정가 주문이 호가 잔량을 순서대로 소진하며 수량가중평균 체결가를 만듭니다.

03

레버리지와 격리 마진

1배부터 50배까지 레버리지를 선택하고 필요한 증거금과 청산가 변화를 확인합니다.

04

포지션과 손익

롱·숏 포지션의 평균 진입가, 실현·미실현 PnL, equity와 가용 잔고를 계산합니다.

05

대기 주문과 자동청산

지정가 주문을 호가 변화에 따라 재평가하고 청산가 도달 여부를 주기적으로 검사합니다.

06

사용자별 모의 계좌

세션 인증으로 사용자의 계좌·주문·체결 내역을 분리해 개인별 학습 기록을 유지합니다.

TERMS IN PLAIN LANGUAGE

핵심 용어를 먼저 설명합니다

선물 모의투자
실제 돈이나 거래소 주문 없이 가상의 자산으로 선물거래 과정을 연습하는 방식입니다.
호가 기반 체결
주문 수량이 매수·매도 호가의 잔량을 순서대로 소진한다고 가정해 체결가를 계산합니다.
격리 마진
포지션에 사용되는 증거금을 별도로 계산하는 방식입니다. 이 프로젝트에서는 학습을 위해 단순화했습니다.
강제청산
평가가격이 계산된 청산가에 도달하면 시스템이 반대 주문을 기록해 포지션을 종료하는 과정입니다.

SCOPE & LIMITATIONS

실제 거래와 무엇이 다른가요?

반영 상위 20호가의 잔량 소진, 부분 체결, 평균 체결가, 롱·숏 손익과 단순 청산가

미반영 maker/taker 수수료, 펀딩비, queue priority, 유지증거금, depth20 밖 유동성과 별도 시장 충격

본 서비스는 학습용 모의투자 도구이며 실제 거래·투자 조언을 제공하지 않습니다. 시세는 Binance 공개 데이터를 사용하며 Binance와 제휴·보증 관계가 없습니다. 단순화된 계산 때문에 실제 거래 결과와 다를 수 있습니다.

FREQUENTLY ASKED QUESTIONS

자주 묻는 질문

실제 돈이 사용되나요?

아닙니다. 가입 시 제공되는 10,000 USDT 모의 자산만 사용하며 실제 거래소 주문이나 자금 이동은 발생하지 않습니다.

어떤 시세 데이터를 사용하나요?

Binance USDⓈ-M Futures의 BTCUSDT 공개 호가 스트림과 캔들 REST 데이터를 사용합니다.

실제 거래 결과와 같나요?

아닙니다. 수수료, 펀딩비, 유지증거금, 호가 깊이와 시장 충격 등이 단순화되어 실제 거래 결과와 다를 수 있습니다.
